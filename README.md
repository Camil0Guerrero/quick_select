# Quick select

A Chrome extension that uses keyboard shortcuts to select the first three items from YouTube search results.

## Features

* Select Youtube search results using keyboard shortcuts
* Visual feedback shows the currently selected item

## Installation

Since the extension is not published on the Chrome Web Store, you can install it locally using Chrome's developer mode.

### 1. Clone the repository

```sh
  git clone https://github.com/Camil0Guerrero/quick_select.git
```

### 2. Open Chrome Extensions

Open the following URL in your browser:
```url
  chrome://extensions
```

Enable **Developer mode** in the top-right corner.

### 3. Load the extension

Click **Load unpacked** and select the extension's folder.

Chrome will install the extension and it will be ready to use.
